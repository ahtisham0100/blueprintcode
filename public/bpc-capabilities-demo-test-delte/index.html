Dynamic pricing and specification

Live totals, quotes and spec sheets as options change.

Price is computed from the configuration, not looked up from a list of SKUs — so a 127-inch screen in a material you only stock in 120 and 135 still gets a correct number. The spec sheet rewrites itself alongside.
